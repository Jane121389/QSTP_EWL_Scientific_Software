# QSTP_EWL_Scientific_Software
QSTP_EWL_Scientific_Software is a scientific Python package for studying the Quantum Sure Thing Principle (QSTP) within the Eisert–Wilkens–Lewenstein (EWL) quantum game framework. It reproduces published results, analyzes perfect entanglers, computes violation metrics, robustness, and generates publication-quality figures and datasets.
